# Bank Visor

A read-only addon for **World of Warcraft Forever** (1.60.1) that lets you check your personal bank and your guild bank from anywhere.

## What it does

- Saves a snapshot of your **personal bank** every time you open it at a banker.
- Saves each **guild bank tab** you visit (the game only sends a tab's contents while you are viewing it).
- Shows everything in one window, with the date of the last update. It keeps data for all your characters.
- Read-only: you can't move or take items. It only shows the last saved state.

## How it works

- Open the window with the **minimap button** or `/vb`.
- Use the **Bank / Guild** tabs, the character dropdown and the search bar. Items that don't match the search are dimmed.
- Hovering an item shows the normal game tooltip, so addons like Auctionator add their prices there. Shift-click links the item in chat.
- The language can be changed from the dropdown in the bottom-right corner (English, Español, Português, Français, Deutsch).

## Install

Copy the `BankVisor` folder into `Interface\AddOns\` in your WoW Forever installation.
